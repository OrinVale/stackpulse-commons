# Security policy

## Reporting a vulnerability

Do not publish credentials, wallet seed phrases, private keys, personal data,
or an exploitable vulnerability in a public issue.

Until a dedicated security contact is published, report a security concern
privately to the project maintainer through the contact method listed with the
public project release. Include enough detail to reproduce the issue without
sharing secrets.

## Scope

The project stores compact comparison state and public source links. It should
never require a donor's private key, seed phrase, exchange password, or
identity document. Requests for any of those items are not legitimate
StackPulse requests.
