# Funding application brief

Use this as a truthful starting point for a grant or sponsorship application.
Customize the ecosystem-specific section only after the requested work genuinely
matches the funder's scope.

## Project summary

StackPulse Commons is an open-source, source-linked research toolkit for
tracking changes in publicly available organization pages over time. It creates
reproducible change events rather than opaque claims: a source is collected,
the first observation becomes a baseline, and only later deltas are shown with
their direct source link.

The project is building a scoped public-interest Web3 ecosystem research pilot.
It will document public-source coverage, taxonomy choices, false-positive
limits, and methodology so communities can inspect the evidence rather than
rely on a black box.

## Current evidence

- Working public Lever connector.
- Compact, versioned state persistence that avoids retaining raw
  job-description text.
- Deterministic fixture and delta-comparison tests.
- Explicit public-source, privacy, and transparency policies.

## 90-day request

**Requested amount:** USD 12,000, with a USD 3,000 minimum viable milestone.

**Deliverables:** reliable source pipeline; scoped Web3 source registry and
taxonomy; reviewed sample dataset; no-login dashboard; recurring public
change report; monthly delivery and funding update.

## Public benefit

The proposed outputs are openly licensed, source-linked, and usable without a
login. They make it easier to inspect observable ecosystem capacity changes
while clearly separating data from interpretation.

## What the project will not do

It will not sell private data, collect authenticated information, issue a
token, offer investment returns, or represent unverified observations as facts.

## Accountability

The project will publish code, methodology, source links, milestone updates,
and funding/spending summaries by category. It will not expose supporter
identity or private financial records.
