# Giveth project listing — ready-to-paste draft

## Project name

**StackPulse Commons — Open Web3 Ecosystem Signals**

## One-line summary

An open-source, source-linked monitor that turns public ecosystem changes into
auditable signals for builders, researchers and public-goods funders.

## Description

StackPulse Commons makes a part of the Web3 ecosystem that is currently
fragmented and anecdotal easier to see: changes in public hiring, technology
adoption and ecosystem capacity. It collects only publicly accessible sources,
records a timestamped snapshot, and publishes the source link and methodology
behind every reported change. The result is a small but useful public signal
layer that builders, researchers, grant operators and community members can
inspect rather than blindly trust.

The project already has a working Python prototype for public job-board
collection, historical comparison, technology extraction, change scoring and a
static dashboard. The Commons roadmap is to harden those pieces into an open,
reproducible Web3 ecosystem pilot: source-linked changes, transparent scoring,
known limitations and a free dashboard. The aim is not to sell private data,
make investment recommendations or create a token. It is to make public
ecosystem information more legible and accountable.

The 90-day pilot has a $12,000 milestone-based budget. The first $3,000 funds a
reliable source pipeline, compact state, test suite and published methodology;
$8,000 adds a scoped Web3 source registry, taxonomy and reviewed sample
dataset; $12,000 adds a no-login dashboard and recurring public report. Code
and Commons outputs will be released under an open license before public
fundraising is promoted. Every funded milestone will receive a public update
describing what shipped, what did not, and the next use of funds.

Donations do not purchase services, equity, tokens or special access. They fund
the freely available Commons work only.
