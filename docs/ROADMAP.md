# 90-day pilot roadmap

## Funding objective

The first funding objective is a **USD 12,000, 90-day foundation pilot**. It is
milestone-led: receiving less funding narrows the scope rather than producing
claims about work that did not ship.

| Funding reached | Deliverable | Evidence published |
| --- | --- | --- |
| USD 3,000 | Reliable public-source pipeline, compact state, methodology baseline | Source policy, test results, first changelog |
| USD 8,000 | Scoped Web3 ecosystem source/taxonomy pilot and quality-review workflow | Source registry, taxonomy version, sample dataset and limitations |
| USD 12,000 | No-login public dashboard and recurring ecosystem change report | Dashboard URL, report archive, funding update |

## Phase 0 — technical integrity

**Now to first funding milestone**

- Replace the oversized historical database with a compact, reviewable state
  file.
- Keep deterministic tests and a public methodology.
- Define source eligibility, error handling, and disclosure language.

Success is a scheduled workflow that creates deltas without retaining raw job
descriptions or failing on GitHub file limits.

## Phase 1 — scoped Web3 research pilot

**After USD 3,000**

- Select a small, documented set of public Web3 ecosystem sources.
- Publish a versioned technology and ecosystem taxonomy.
- Manually review a sample of events for false positives and document the
  outcome.
- Release the first source-linked pilot dataset and changelog.

Success is not maximum coverage. It is a transparent, auditable baseline with
known limitations.

## Phase 2 — public reporting

**After USD 8,000**

- Publish a simple no-login dashboard.
- Produce a recurring report that distinguishes observations from inference.
- Add issue templates for corrections, source removals, and methodology
  feedback.

## Phase 3 — sustainable stewardship

**After USD 12,000**

- Publish monthly funding and delivery updates.
- Invite external review of taxonomy and source policy.
- Evaluate the appropriate legal and governance structure before accepting
  larger or restricted funding.

## Non-goals for this pilot

- No token launch, equity offering, or donor reward scheme.
- No private-data collection or personal-data enrichment.
- No claim that public job changes prove commercial intent or investment value.
- No guarantee of grants, donations, coverage, or adoption.
