# Contributing

Thank you for considering a contribution to StackPulse Commons.

## Before proposing a change

- Read the [methodology](docs/METHODOLOGY.md) and preserve its distinction
  between observation and inference.
- Do not add a source that requires authentication, circumvention of access
  controls, or collection of private data.
- Keep new terminology versioned and explain likely false positives.
- Add or update deterministic tests for changes to event logic.

## Pull requests

Use a focused pull request with:

1. a plain-language problem statement;
2. the source or methodology impact;
3. test results; and
4. any privacy, licensing, or rate-limit considerations.

Please avoid submitting real personal data, credentials, wallet secrets, or
unredacted private documents.
