# StackPulse Commons changelog

## 2026-09-27 — First public baseline

StackPulse Commons has completed its first public baseline.

### What is available

- 210 public Lever sources discovered and validated by the source workflow.
- A public Lever connector, compact comparison state, and deterministic
  fixture/delta-comparison tests.
- Automated source discovery and crawl workflows.
- Public methodology, governance, roadmap, and funding documentation.

### What this baseline means

The first successful observation of a source is a baseline, not a change event.
StackPulse reports source-linked changes only after a later comparison. The
project does not retain full job-description text and does not treat an observed
public change as proof of a purchase, funding decision, hiring plan, or
investment signal.

### Next public milestone

The first funding milestone is **USD 3,000**. It sustains the public-source
pipeline, funds source review and methodology refinement, and delivers the
first public changelog update with completed work, material limitations, and
